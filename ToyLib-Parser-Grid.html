matP :: MonadState ByteString m => Int -> Int -> m (IxVector (Int, Int) (Vector Int)) Source #

\(O(HW)\) Reads next h * w elements as matrix of type a.

Example

Input:

1 2 3
4 5 6

Parsed result:

4 5 6
