twoPointersU :: Int -> (Int -> Int -> Bool) -> Vector (Int, Int) Source #

\(O(f N)\) Stateless two pointer method over a range. Returns the longest non-null inclusive ranges for each l that satisfy the given check.

REMARK: Use accumulate if you need empty intervals.

U.accumulate max (U.generate n pred) (twoPointersU n p)
